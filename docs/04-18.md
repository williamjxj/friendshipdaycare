### 3. Six Google Fonts Loaded — Hurts Core Web Vitals

**Why it matters:** Google uses Core Web Vitals (LCP, CLS, INP) as a direct ranking factor. Loading 6 font families adds ~600ms of render-blocking load time on mobile — this can drop your score from "Good" to "Needs Improvement."

**The bug:** `src/app/layout.tsx` imports all of these:

```ts
import { Nunito, Fredoka, Baloo_2, Comic_Neue, DM_Sans, Source_Sans_3 } from "next/font/google";
```

**Fix:** Reduce to 2 fonts maximum. Keep one display font and one body font:

```ts
// Keep only:
import { Nunito, Fredoka } from "next/font/google";

// Remove: Baloo_2, Comic_Neue, DM_Sans, Source_Sans_3
```

Also add `display: 'swap'` to prevent invisible text during font load:

```ts
const nunito = Nunito({
  variable: "--font-nunito",
  subsets: ["latin"],
  weight: ["400", "500", "600", "700"],
  display: "swap",  // ← add this
});
```

**Verify your score** before and after at [pagespeed.web.dev](https://pagespeed.web.dev) — aim for 90+ on mobile.

### 6. Add FAQ Schema for Rich Results

**Why it matters:** FAQ rich results can double the height of your Google listing, pushing competitors further down the page. They appear as expandable questions directly under your result.

**Fix:** Add a `FAQPage` schema component and include it in your homepage. Create `src/components/seo/FAQSchema.tsx`:

```tsx
export function FAQSchema() {
  const schema = {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": [
      {
        "@type": "Question",
        "name": "What ages does Friendship Corner Daycare accept?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "We accept children from 30 months to 5 years old in our licensed Montessori daycare in Coquitlam, BC."
        }
      },
      {
        "@type": "Question",
        "name": "Where is Friendship Corner Daycare located?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "We are located at 2950 Dewdney Trunk Road, Coquitlam, BC V3C 6E7, near Coquitlam Centre."
        }
      },
      {
        "@type": "Question",
        "name": "Is the daycare licensed in BC?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "Yes, Friendship Corner Daycare is a fully licensed childcare facility in BC, operating since 2008."
        }
      },
      {
        "@type": "Question",
        "name": "What are your hours?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "We are open Monday to Friday, 7:00 AM to 6:00 PM."
        }
      },
      {
        "@type": "Question",
        "name": "Do you offer Montessori education?",
        "acceptedAnswer": {
          "@type": "Answer",
          "text": "Yes, we offer an authentic Montessori program for children aged 30 months to 5 years, with certified ECE teachers."
        }
      }
    ]
  };

  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(schema) }}
    />
  );
}
```

Then add `<FAQSchema />` inside the `<head>` block in `src/app/layout.tsx`.

### 8. Sitemap Uses Dynamic Dates — Misleads Google

**Why it matters:** When every page always shows `lastModified: now` (the current moment), Google learns the signal is meaningless and stops using it to prioritize recrawling your content.

**The bug:** In `src/app/sitemap.ts`:
```ts
const now = new Date();
// ...
lastModified: now,  // used on every single page
```

**Fix:** Use real dates that reflect when you actually updated each page:

```ts
export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: baseUrl,
      lastModified: new Date("2025-04-01"),  // update when homepage changes
      changeFrequency: "monthly",
      priority: 1
    },
    {
      url: `${baseUrl}/our-team`,
      lastModified: new Date("2025-01-15"),
      changeFrequency: "monthly",
      priority: 0.75
    },
    // ... update dates when you actually modify content
  ];
}
```

**Setup steps:**
